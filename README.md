## عامل تحلیل‌گر و اصلاح‌گر کامپایلر (SimpleLang Compiler Agent)

این برنامه چیست؟

این پروژه یک عامل تحلیل‌گر کامپایلر سه‌مرحله‌ای است که کد ورودی را بدون استفاده از هیچ‌گونه مدل هوش مصنوعی (AI/LLM) و کاملاً با الگوریتم‌های قطعی و دست‌نویس (Rule-Based) در سه فاز اصلی بررسی می‌کند:


### تحلیل واژگانی (Lexical Analysis): کاراکترهای کد را به توکن‌های معتبر (کلمات کلیدی، شناسه‌ها، اعداد، عملگرها) تبدیل می‌کند و خطاهایی مثل کاراکتر نامعتبر، رشته بازمانده یا عدد اعشاری اشتباه را پیدا می‌کند.


### تحلیل نحوی (Syntax Analysis): بر اساس گرامر مستقل از متن (CFG)، درخت تجزیه (AST) می‌سازد و خطاهایی مثل جا افتادن سمی‌کالن (;)، بسته‌نشدن پرانتز یا آکولاد ({}) و ساختار اشتباه `if / while `را تشخیص می‌دهد.


### تحلیل معنایی (Semantic Analysis): با ساخت جدول نمادها (Symbol Table)، اعلان‌نشدن متغیرها، اعلان تکراری، ناسازگاری نوع داده (int، float، string، bool)، تقسیم بر صفر و غلط املایی نام متغیرها (با الگوریتم فاصله لونشتاین) را شناسایی می‌کند.


علاوه بر نمایش دلیل علمی هر خطا، برنامه می‌تواند کد را به‌صورت خودکار یا تک‌به‌تک اصلاح کند.

----------------------------------------

### تکنولوژی‌های استفاده‌شده (Tech Stack)

*رابط کاربری*: React + TypeScript


*استایل و طراحی واکنش‌گرا (موبایل و دسکتاپ)*: Tailwind CSS


*ابزار ساخت و اجرا (Build Tool)*: Vite


*آیکون‌ها*: Lucide React


*موتور کامپایلر*: پیاده‌سازی اختصاصی Lexer، Recursive-Descent Parser، Semantic Analyzer و ماژول اصلاح خطای مبتنی بر قواعد (بدون کتابخانه کامپایلر آماده و بدون هوش مصنوعی) — همراه با نسخه پایتون استاندارد در پروژه


--------------------------------------------------------------------------
### راهنمای سریع استفاده


1. انتخاب نمونه کد یا نوشتن کد جدید:

در کادر سمت چپ (یا بالا در موبایل)، از منوی Preset یکی از کدهای آماده (خطاهای واژگانی، نحوی، معنایی یا کد سالم) را انتخاب کنید یا کد خودتان را بنویسید.


2. اجرای تحلیل:

با تایپ یا تغییر کد، تحلیل به‌صورت خودکار انجام می‌شود؛ همچنین می‌توانید دکمه Run Analysis (پایین ویرایشگر) یا Analyze Code (نوار بالا) را بزنید تا نتیجه و زمان آخرین بررسی با هایلایت سبز نمایش داده شود.


3. بررسی خطاها در پنل Diagnostics:

سه کارت بالای پنل نشان می‌دهند هر کدام از فازهای Lexical، Syntax و Semantic چند خطا داشته‌اند. با کلیک روی هر کارت یا تب‌های فیلتر می‌توانید فقط خطاهای همان فاز را ببینید.

برای هر خطا، شماره خط و ستون، محل دقیق خطا با نشانگر ^، قانون نقض‌شده و پیشنهاد اصلاح نمایش داده می‌شود.


4. اصلاح خطاها (Auto-Correct):

اصلاح تکی: روی دکمه Fix → کنار هر خطا بزنید تا فقط همان خطا اصلاح شود.


اصلاح همه خطاها: روی Auto-Correct (یا Auto-Fix All) کلیک کنید تا پنجره پیش‌نمایش باز شود؛ در آنجا لیست تغییرات و مقایسه کد قبل و بعد را ببینید و با زدن Apply اصلاحات را اعمال کنید.


مشاهده خروجی مراحل کامپایلر (تب‌های بالای صفحه):

Lexical Tokens: جدول کامل توکن‌های استخراج‌شده به‌همراه نوع و موقعیت آن‌ها.

Syntax AST Tree: نمایش گرافیکی و درختی ساختار نحوی برنامه.

Symbol Table: جدول متغیرهای تعریف‌شده، نوع داده، اسکوپ و مقداردهی اولیه آن‌ها.
